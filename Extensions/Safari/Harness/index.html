How Transformers Learn to Attend

The Transformer dispenses with recurrence entirely, relying on attention to draw global dependencies between input and output. This allows for significantly more parallelization than recurrent networks.

In practice, each layer computes softmax(QKᵀ/√d)V for every head. The scaling factor keeps the dot products from growing so large that the softmax saturates, which would leave the gradients vanishingly small.

Why it works

The latter point matters more than it first appears. Without it, training diverges within the first few hundred steps on most configurations we tried.

“Attention is not explanation” — but it is a surprisingly good place to start looking.
def attention(q, k, v):
    scores = q @ k.T / math.sqrt(q.shape[-1])
    return softmax(scores) @ v
  • Multi-head attention lets the model attend to information from different representation subspaces.
    • Each head has its own projection matrices.
    • Heads are concatenated and projected once more.
  • Positional encodings inject order information, since attention itself is permutation-invariant.
